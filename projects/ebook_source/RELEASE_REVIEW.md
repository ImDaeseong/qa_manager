상태: **HOLD**. 자동 검사는 공개 배포 구조, 실행 예제, 템플릿, 샘플 프로젝트와 `ebook` 동기화 계약을 재검증한다. 실제 독자 사용성, 외부 서비스, 권리, 운영 및 최종 출간 승인은 대신하지 않는다.

## 기능 적합성
- `verify_distribution.py`가 시스템·예제·템플릿·샘플 프로젝트와 fresh-copy build를 검사한다. 실제 독자 성공률은 미검증이다.

## 성능 효율성
- 전체 검증은 300초 제한 안에서 실행되지만, 최소 하드웨어·용량·성능 기준은 미정이다.

## 호환성
- Windows와 일부 WSL 경로를 검증했다. macOS·다른 Python/Node 조합은 HOLD다.

## 상호작용 능력
- 각 샘플 프로젝트에 별도 시작 지점과 쉬운 설명이 있다. 비전문가 사용성 관찰은 미실시다.

## 신뢰성
- 실패 시 비정상 산출물을 PASS로 인증하지 않는 가드와 fresh-copy 재빌드가 있다. 장기 운영·복구 훈련은 미검증이다.

## 보안
- 로컬 절대 경로, 비밀값 형태, 공개 제외 경계를 검사한다. 전문 보안 감사와 실제 외부 서비스 인증 검토는 HOLD다.

## 유지보수성
- 폴더별 책임, `companion_contract.json`, 공식 검증 명령과 재현 프롬프트가 있다. 예제 복제본 간 장기 드리프트 검토는 계속 필요하다.

## 유연성 이식성
- 로컬 사용자 경로를 고정하지 않고 상대경로 계약을 검사한다. 모든 지원 운영체제에서의 실행은 확정하지 않았다.

## 안전성
- 외부 전송·유료 호출·자동 승인을 HOLD로 분리한다. 예제를 실제 운영 시스템으로 직접 사용하는 범위는 승인하지 않았다.

## 실사용 품질
- 자동 PASS는 학습 효과, 이해도, 업무 성과를 보장하지 않는다. 목표 독자의 실제 실습 관찰이 남아 있다.
