R1 통과 스킬(도구 설명서) 저장소 전체가 정해진 규칙을 지키고 있어야 한다 — 이름/설명이 빠짐없고, 목록 파일과 실제 폴더가 일치하며, 안내 문서의 경로 연결이 끊어지지 않아야 한다

커버리지: 개발항목 1개 · 검사항목 1개 연결됨

R1-D1 통과 전체 규칙 준수 검사 — 모든 스킬 문서와 안내 문서를 오늘 날짜 기준으로 검사
  • validate-workspace-guard 통합검사 통과

    각 스킬 설명서의 이름이 폴더명과 일치하는지, 공통 규칙 문서를 따른다고 명시했는지, 목록 파일(marketplace.json)이 실제 폴더 구성과 정확히 일치하는지, 문서 안 날짜가 미래로 잘못 적히지 않았는지 등을 확인합니다.

    실행 명령: powershell.exe -NoProfile -Command "$asOfDate=[TimeZoneInfo]::ConvertTimeBySystemTimeZoneId([DateTime]::UtcNow,'Korea Standard Time').Date; & ./scripts/validate_workspace.ps1 -AsOfDate $asOfDate"

R2 통과 문서 안의 내부 링크가 깨지지 않아야 한다

커버리지: 개발항목 1개 · 검사항목 1개 연결됨

R2-D1 통과 문서 내부 링크 검사
  • validate-links-guard 기본검사 통과

    문서 안에 있는 다른 문서로의 링크가 실제로 존재하는 파일을 가리키는지 저장소 전체에서 확인합니다.

    실행 명령: powershell.exe -NoProfile -File scripts/validate_links.ps1

R3 통과 검사 도구가 검사 대상에서 제외해야 할 폴더(별도 관리되는 하위 프로젝트 등)를 정확히 제외하고 있어야 한다

커버리지: 개발항목 1개 · 검사항목 1개 연결됨

R3-D1 통과 제외 목록 처리 검사
  • validators-ignore-scan-regression 재발방지검사 통과

    임시 복사본에서 접근 불가 런타임·캐시 제외, 코드형 제목 링크, 신규 스킬 반영·경로 초기화·보안 지침을 정상/결함 주입 19개 사례로 검사합니다.

    실행 명령: powershell.exe -NoProfile -File scripts/test_validators_ignore_scan.ps1

R4 통과 커밋되는 파일에 실제로 사용 가능한 비밀정보(API 키, 토큰)가 들어가면 안 된다

커버리지: 개발항목 2개 · 검사항목 2개 연결됨

R4-D1 통과 비밀정보처럼 보이는 값 패턴 검사 — hermes-agents의 동일 가드를 이식
  • no-example-secrets-guard 기본검사 통과

    저장소에 올라가는 파일에 실제로 사용 가능한 비밀번호나 인증키가 실수로 포함되지 않았는지 확인합니다.

    실행 명령: powershell.exe -NoProfile -File scripts/check_no_example_secrets.ps1

R4-D2 통과 패턴 목록이 실제로 심어둔 가짜 비밀키를 잡아내고, 평범한 문장에는 반응하지 않는지 검사
  • no-example-secrets-guard-regression 재발방지검사 통과

    비밀정보 탐지 패턴이 실제 가짜 비밀키 형태를 놓치지 않고, 평범한 텍스트를 오탐하지 않는지 확인합니다. 2026-09-18: 단일행 파일을 건너뛰던 실제 결함(ai_prompt의 동일 가드에서 발견)을 이 저장소에서도 확인·수정, 회귀 케이스 추가.

    실행 명령: powershell.exe -NoProfile -File scripts/test_check_no_example_secrets.ps1

R5 통과 커밋되는 소스 코드에 OWASP/CWE 근거 기반 보안·해킹·네트워크 허점이 미검토 상태로 남으면 안 된다
