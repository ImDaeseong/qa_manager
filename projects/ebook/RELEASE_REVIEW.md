# ebook 출시 검토

상태: **HOLD**. 자동 검사는 판매 후보의 기술적 일관성과 현재 출시 차단 사유를
확인하지만 전문 교정, 실제 독자 관찰, EPUB 리더 화면, 판매 채널 등록을 대신하지 않는다.
공개 QA 보고서는 원고 본문이나 독자·권리 기록의 내용을 복사하지 않고 검사 명령과
판정만 표시한다.

## 기능 적합성
- 자동 회귀 검사와 원고 계약 검사는 PASS다. 실제 독자 결과는 HOLD다.

## 성능 효율성
- 검사 시간과 EPUB 용량의 출시 임계값은 아직 정하지 않았다.

## 호환성
- EPUBCheck·Ace 기록은 있으나 실제 리더 조합의 사람 검토가 남아 있다.

## 상호작용 능력
- 이미지 자동 검사는 PASS다. 실제 판매 화면과 EPUB 탐색은 HOLD다.

## 신뢰성
- 음성 검사와 불완전 산출물 차단 검사는 PASS다. 배포·복구 훈련은 미검토다.

## 보안
- 공개 QA에는 원고 본문과 민감 기록을 포함하지 않는다. 전체 검토는 미완료다.

## 유지보수성
- 원고·강의·편집 계약을 재실행할 수 있다. 독립 Git 이력은 없는 폴더다.

## 유연성 이식성
- Python 명령은 Windows에서 검증됐다. 다른 지원 환경은 정하지 않았다.

## 안전성
- 두 판매 채널 모두 정확한 사람 검토 사유로 HOLD한다.

## 실사용 품질
- AI 모의 독자 검사는 있으나 실제 표적 독자 관찰은 NOT RUN/HOLD다.

## 개인정보 데이터 거버넌스
- 공개 QA는 원고와 독자 기록을 게시하지 않는다. 판매 데이터 처리는 미검토다.

## 공급망 라이선스
- 권리·코드 출처 원장이 있지만 최종 판매 책임자 검토는 HOLD다.

## 배포 운영
- 판매 후보 EPUB은 존재한다. 실제 업로드·롤백·지원 절차는 미검토다.

## 법률 규제
- 대한민국 판매를 가정한다. 최종 권리·약관·세무 판단은 별도 검토가 필요하다.

## 사업 운영
- 부크크·크몽 상품 정보와 판매 파일 판정이 아직 HOLD다.
